# Struct4Search

Struct4Search는 기업 내에 축적된 비정형 문서(PDF, PPT, HWP 등)를 대상으로, 데이터 외부 반출 없이 기업 내부 환경에서 문서의 시각적 구조와 의미 정보를 멀티모달 AI로 이해하고 지식으로 증강하여 검색 표현을 재구성함으로써, 기존 텍스트 중심 검색 시스템의 한계를 극복하는 멀티모달 지능형 검색 솔루션입니다.

기업의 다양한 비정형 문서에서 숨겨진 지식(텍스트/표/그래프/도면 등)을 빠르고 정확하게 이해하고 검색할 수 있는 내부 구축형 표준 검색 플랫폼을 목표로 합니다.

## 시스템 구성도

![Struct4Search 시스템 구조](/img/struct4search-system-architecture.png)

Struct4Search는 두 개의 파이프라인으로 구성됩니다.

- **문서 인덱싱 파이프라인**은 문서를 파싱하고 원문 청크, Metadata, 지식그래프와 검색표현을 생성한 뒤 검색 가능한 형태로 저장합니다.
- **검색·답변 파이프라인**은 사용자 질의를 기반으로 관련 원문과 검색표현을 검색하고, 최종 원문 근거를 구성해 답변과 출처를 반환합니다.

문서 인덱싱 파이프라인의 출력은 검색·답변 파이프라인의 검색 기반이 됩니다. 앞 단계가 원본 문서를 검색 가능한 지식으로 변환한다면, 뒤 단계는 그 지식에서 관련 원문을 찾아 근거가 연결된 답변으로 반환합니다. 각 단계의 상세한 순서와 입출력은 [데이터 흐름](concepts/data-flow.md)에서 확인할 수 있습니다.

## 검색 단위와 답변 근거

검색에는 두 종류의 데이터가 사용됩니다.

- **원문 청크**: 문서에서 직접 가져온 원문 검색 단위
- **검색표현**: Metadata와 지식그래프를 이용해 만든 검색 보조 표현

검색표현은 관련 원문을 더 잘 찾기 위해 사용하지만, 답변의 사실 근거와 Citation에는 원문 청크만 사용합니다.
