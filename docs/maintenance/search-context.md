# 검색과 Context 수정

검색 후보 수, 최종 근거 수와 LLM Context 구성을 변경할 때 확인해야 하는 항목입니다. 검색·답변 단계의 변경이므로 기존 색인은 그대로 사용할 수 있습니다.

## 값 사이의 관계

검색 후보 수와 최종 근거 수는 순서대로 연결되어 있습니다.

| 값 | 현재값 | 역할 |
|---|---:|---|
| `query.native_rrf.bm25_depth` · `dense_depth` | 50 | BM25·Dense 채널별 후보 깊이 |
| `query.native_rrf.pagination_depth` | 50 | Hybrid 검색에서 채널별로 탐색하는 후보 깊이 |
| `query.native_rrf.rrf_rank_constant` | 60 | RRF 순위 통합에 사용하는 상수 |
| `query.native_rrf.combined_depth` | 30 | OpenSearch가 반환하는 RRF 후보 수 |
| `query.native_rrf.final_source_top_k` | 10 | 최종 답변 근거로 사용할 원문 청크 수 |
| `query.reader.generation.context_window_tokens` | 16384 | 답변 모델이 처리할 수 있는 전체 Context 크기 |

```text
채널별 후보 50
    ↓
RRF Top-30
    ↓
Top-10 원문 청크
    ↓
LLM Context
    ↓
답변 생성
```

채널별 후보 수를 줄이면 RRF가 비교할 수 있는 검색 결과가 줄어듭니다. RRF 후보 수를 줄이면 검색표현을 원문 청크로 연결하고 중복을 정리한 뒤 최종 Top-10을 충분히 구성하지 못할 수 있습니다.

최종 근거 수를 늘리면 LLM Context도 길어집니다. 답변에 사용할 수 있는 출력 토큰은 전체 Context Window에서 프롬프트와 근거가 사용한 만큼을 제외하고 결정되므로, 근거가 길어질수록 답변에 사용할 수 있는 범위는 줄어듭니다.

## 현재 검색 계약

현재 검색·답변 파이프라인은 다음 값을 사용합니다.

- BM25 후보 깊이: 50
- Dense 후보 깊이: 50
- RRF 후보: 30
- RRF 상수: 60
- 최종 원문 근거: 최대 10개

이 값들은 서로 연결되어 있으므로 하나를 변경할 때도 이후 단계에 미치는 영향을 함께 확인해야 합니다.

## 점수 통합 방식을 바꿀 때

RRF Top-30 이후의 점수 통합 방식은 [검색 결과 점수 통합](../query/score-integration.md)에서 처리합니다.

현재 방식은 다음 계약을 따릅니다.

- 검색표현의 점수를 연결된 원문 청크에 전달합니다.
- 같은 원문 청크가 여러 점수를 받으면 Max Score를 사용합니다.
- 같은 원문 청크는 최종 순위에 한 번만 남습니다.
- 최종 Top-10은 원문 청크로만 구성됩니다.

점수 통합 방식을 변경하면 검색 결과 자체가 달라지므로 검색과 QA 성능을 함께 확인합니다.

## Context 구성을 바꿀 때

[LLM Context 구성](../query/context.md)은 최종 Top-10 원문 청크를 답변 근거로 사용합니다.

검색표현을 통해 검색된 청크에는 해당 검색표현을 보조 정보로 함께 제공하지만, 검색표현은 답변의 사실 근거나 Citation으로 사용할 수 없습니다.

Context의 근거 형식, 검색표현 표시 방식이나 근거 수를 변경하면 답변 모델이 받는 입력이 달라지므로 QA 결과도 함께 확인해야 합니다.

## 변경 후 확인

검색·Context 설정을 변경해도 기존 인덱스를 다시 만들 필요는 없습니다.

다만 검색 결과나 답변 입력이 달라질 수 있으므로 변경 내용에 따라 다음을 다시 평가합니다.

| 변경 | 검색 평가 | QA 평가 |
|---|---|---|
| 채널별 후보 수·RRF 설정 | 필요 | 필요 |
| 최종 Top-10 구성 방식 | 필요 | 필요 |
| 점수 통합 방식 | 필요 | 필요 |
| Context 근거 수·구성 | — | 필요 |
| 검색표현 표시 방식 | — | 필요 |

평가 방법과 회귀 판정 기준은 [기준 성능과 회귀 판정](../testing/regression-gates.md)에서 확인할 수 있습니다.
