# 평가셋 구성

평가에는 목적이 다른 두 가지 고정 평가셋을 사용합니다.

| 평가셋     |    문서 |  질의 | 목적               |
| ------- | ----: | --: | ---------------- |
| 소규모 평가셋 |   100 | 100 | 변경 중 빠른 성능 확인    |
| 대규모 평가셋 | 2,567 | 200 | 기준선 비교와 최종 회귀 확인 |

두 평가셋의 질의와 정답은 **원본 문서를 직접 확인해** 작성했습니다. 기존 검색표현·검색 결과·지식그래프·RAG 출력은 질의나 정답을 만드는 데 사용하지 않았습니다.

## 소규모 평가셋 — 100문서·100질의

| 항목    |                   수 |
| ----- | ------------------: |
| 문서    |                 100 |
| 질의    | 100 (`q001`–`q100`) |
| qrels |                 130 |
| 정답 답변 |                 100 |

### 질의 구성

| 구분                       |                  수 |
| ------------------------ | -----------------: |
| Single-hop               | 75 (`q001`–`q075`) |
| Cross-document Multi-hop | 25 (`q076`–`q100`) |

질의의 출발점은 필요 우선 48건, 원문 유도 중요정보 38건, 구조화 커버리지 14건으로 구성됩니다. 질의 형태는 질문 79건, 요청 12건, 키워드 9건입니다.

검색 공간이 100문서로 제한되어 있어 대규모 검색 환경의 난이도를 그대로 반영하지는 않습니다. 변경 중 성능 방향이 크게 달라지지 않았는지 빠르게 확인하는 용도로 사용합니다.

### 자산 파일

| 파일                             | 내용                     |
| ------------------------------ | ---------------------- |
| `documents.jsonl`              | 문서 목록과 파일 해시           |
| `queries.jsonl`                | 질의                     |
| `qrels.jsonl`                  | 질의별 정답 근거              |
| `answers.jsonl`                | 정답 답변                  |
| `evidence.jsonl`               | 근거 구간                  |
| `multi_hop_dependencies.jsonl` | Multi-hop 질의의 문서 의존 관계 |
| `dataset.jsonl`                | 평가 자산을 묶은 마스터 파일       |

## 대규모 평가셋 — 2,567문서·200질의

| 항목    |                   수 |
| ----- | ------------------: |
| 문서    |               2,567 |
| 질의    | 200 (`q001`–`q200`) |
| qrels |                 242 |
| 정답 답변 |                 200 |
| 정답 문서 |                 166 |
| 원문 근거 |                 350 |

### 질의 구성

| 유형                                                                             |    수 |
| ------------------------------------------------------------------------------ | ---: |
| Multi-hop                                                                      |   32 |
| Open-ended · Extractive · Compare-contrast · Boolean · Numerical · Enumerative | 각 28 |

근거 범위는 single-page 146건, cross-page 13건, cross-document 41건입니다. 질의 길이는 4–12어절이며 평균 6.7어절로 구성되어 있습니다.

검색 공간이 2,567문서이므로 **기준 성능과 회귀 판정은 이 평가셋을 기준으로 합니다.**

### 자산 파일

| 파일                      | 내용               |
| ----------------------- | ---------------- |
| `corpus_manifest.jsonl` | 검색 대상 문서 2,567건  |
| `queries.jsonl`         | 질의               |
| `qrels.jsonl`           | 질의별 정답 근거        |
| `qa_gt.jsonl`           | 정답 답변            |
| `gt_documents.jsonl`    | 정답 문서            |
| `dataset.jsonl`         | 평가 자산을 묶은 마스터 파일 |

평가셋 릴리스는 `configs/evaluation-release.json`에서 선언합니다. 실제 파일의 행 수가 선언된 값과 다르면 평가를 시작하지 않습니다.

## 자산은 한 곳에서 해석합니다

평가 실행기는 각 자산의 경로를 개별적으로 지정하지 않고 릴리스 정의를 기준으로 평가셋을 불러옵니다. 서로 다른 평가 자산으로 생성한 결과를 같은 조건의 결과처럼 비교하는 일을 막기 위한 구조입니다.

## 수정 규칙

평가셋 자체가 바뀌면 이전 결과와 같은 기준으로 비교할 수 없습니다.

* 질의나 정답을 수정하면 **새 릴리스로 만듭니다.** 같은 릴리스의 자산을 그대로 수정하지 않습니다.
* 릴리스에 선언된 자산 수를 함께 갱신합니다. 실제 파일과 선언 값이 다르면 평가가 거부됩니다.
* 새 릴리스에서 기준 성능을 다시 측정합니다. 이전 기준선은 이전 평가셋 릴리스에만 적용됩니다([기준 성능과 회귀 판정](regression-gates.md)).
