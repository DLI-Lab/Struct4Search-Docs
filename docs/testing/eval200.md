# 평가셋 구성

평가에 쓰는 고정 자산은 두 가지입니다. 목적이 다르므로 상황에 맞게 고릅니다.

| 평가셋 | 문서 | 질의 | 목적 |
|---|---:|---:|---|
| 소규모 | 100 | 100 | 변경 중 빠르게 확인 |
| 전체 코퍼스 | 2,567 | 200 | 병합 전 기준선 비교 |

두 평가셋 모두 질의와 정답을 **원본 문서를 직접 확인해** 만들었습니다. 기존 검색표현·검색 결과·지식그래프·RAG 출력은 질의나 정답을 만드는 데 쓰지 않았습니다.

## 소규모 평가셋 — 100문서 100질의

| 항목 | 수 |
|---|---:|
| 문서 | 100 |
| 질의 | 100 (`q001`–`q100`) |
| qrels | 130 |
| 정답 답변 | 100 |

### 질의 구성

| 구분 | 수 |
|---|---:|
| Single-hop | 75 (`q001`–`q075`) |
| Cross-document Multi-hop | 25 (`q076`–`q100`) |

질의를 만든 출발점도 셋으로 나뉩니다 — 필요 우선 48, 원문 유도 중요정보 38, 구조화 커버리지 14. 형태는 질문 79, 요청 12, 키워드 9입니다.

**검색 공간이 100문서입니다.** 그래서 이 평가셋의 점수는 실제 규모의 난이도를 보여 주지 않습니다. 변경이 방향을 크게 틀지 않았는지 빠르게 보는 용도입니다.

### 자산 파일

| 파일 | 내용 |
|---|---|
| `documents.jsonl` | 문서 목록과 파일 해시 |
| `queries.jsonl` | 질의 |
| `qrels.jsonl` | 질의별 정답 근거 |
| `answers.jsonl` | 정답 답변 |
| `evidence.jsonl` | 근거 구간 |
| `multi_hop_dependencies.jsonl` | Multi-hop 질의의 문서 의존 관계 |
| `dataset.jsonl` | 위를 묶은 마스터 |

## 전체 코퍼스 평가셋 — 2,567문서 200질의

| 항목 | 수 |
|---|---:|
| 문서 | 2,567 |
| 질의 | 200 (`q001`–`q200`) |
| qrels | 242 |
| 정답 답변 | 200 |
| 정답 문서 | 166 |
| 원문 근거 | 350 |

### 질의 구성

| 유형 | 수 |
|---|---:|
| multi-hop | 32 |
| open-ended · extractive · compare-contrast · boolean · numerical · enumerative | 각 28 |

근거의 범위는 single-page 146, cross-page 13, cross-document 41입니다. 질의 길이는 4–12어절이고 평균 6.7어절로, 실제 안전업무에서 쓸 법한 짧은 표현입니다.

**검색 공간이 2,567문서입니다.** 성능 판정은 이 평가셋으로 합니다.

### 자산 파일

| 파일 | 내용 |
|---|---|
| `corpus_manifest.jsonl` | 검색 대상 문서 2,567건 |
| `queries.jsonl` | 질의 |
| `qrels.jsonl` | 질의별 정답 근거 |
| `qa_gt.jsonl` | 정답 답변 |
| `gt_documents.jsonl` | 정답 문서 |
| `dataset.jsonl` | 위를 묶은 마스터 |

이 릴리스는 `configs/evaluation-release.json`이 선언합니다. 파일의 행 수가 선언과 다르면 평가가 시작되지 않습니다.

## 자산은 한 곳에서만 해석합니다

실행기가 자기 경로를 직접 들지 않고 릴리스 정의 한 곳에서 해석합니다. 서로 다른 자산으로 낸 결과를 같은 값처럼 비교하는 일을 막기 위한 것입니다.

## 수정 규칙

평가셋을 고치면 그 전후의 지표를 비교할 수 없습니다.

- 질의나 정답을 바꾸면 **새 릴리스로 만듭니다.** 같은 릴리스 안에서 조용히 고치지 않습니다.
- 선언된 수를 함께 갱신합니다. 파일과 선언이 어긋나면 평가가 거부합니다.
- 기준 성능을 다시 측정합니다. 이전 기준선은 이전 릴리스의 값입니다([기준 성능과 회귀 판정](regression-gates.md)).
